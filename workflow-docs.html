Supported Content Types

Everything you send to your Telegram bot gets intelligently processed

Links & URLs

Automatically extracts and names links, selects categories, and generates descriptions for saved bookmarks.

Voice Notes

Transcribed using OpenAI Whisper, then analyzed and organized like any other note.

Images & Photos

Photos and images are saved with captions analyzed and embedded in your Notion pages.

Task Detection

AI detects tasks and to-dos, extracts due dates, and assigns priority levels automatically.

Smart Tagging

Uses existing tags when appropriate and creates new ones for better organization.

AI Descriptions

Every entry gets a helpful 2-3 sentence description summarizing the content.

Database Properties

Your Notion "Notebook" database needs these properties

Property Type Description
Name Title AI-generated title for the entry
URL URL Link URL if the entry contains a web link
Category Select Content category (Articles, Ideas, Tasks, Notes, etc.)
Tags Multi-select Relevant tags (AI creates new ones as needed)
Description Rich Text AI-generated 2-3 sentence summary
Created Date When the entry was received
Is Task Checkbox Whether this is a task/to-do item
Due Date Date Task due date (extracted from natural language)
Priority Select High / Medium / Low
Content Type Select Link, Text, Voice, Image, Video, Document

Quick Setup Guide

Get running in 5 simple steps

1

Create Telegram Bot

Open Telegram and message @BotFather with /newbot. Save the API token you receive.

2

Set Up Notion Database

Create a database called "Notebook" with the properties listed above. Create a Notion integration at notion.so/my-integrations and share the database with it.

3

Get Your API Keys

  • Telegram Bot Token (from BotFather)
  • Notion Integration Token
  • OpenAI API Key (for GPT-4o and Whisper)
  • Notion Database ID (from database URL)
4

Import to n8n

Download the workflow file and import it in n8n via Workflows → Import from File. Configure your credentials in the Credentials section.

5

Activate & Test

Toggle the workflow to "Active" and send a test message to your Telegram bot. Watch the magic happen!
